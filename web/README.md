# GameMaster website

Next.js app for the GameMaster map, calendar, games, attendance, and server setup. It uses the same MySQL database as the Discord bot.

Setup, environment variables, and how to start the bot are in the repository [README](../README.md). Copy `.env.example` to `.env.local` before `npm run dev`.

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000). The public invite page is [http://localhost:3000/invite](http://localhost:3000/invite).
